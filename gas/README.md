# スプレッドシート連携のセットアップ

工事費判定ツールの管理者ページで保存した工事費を Google スプレッドシートに保存し、全端末で共有するための設定手順です。

## 1. スプレッドシートを作成する

1. Google ドライブで新しいスプレッドシートを作成します（名前は自由。例：`SCTV工事費設定`）。
2. メニュー「拡張機能」→「Apps Script」を開きます。
3. 最初から入っている `コード.gs` の中身をすべて消し、このフォルダの [`Code.gs`](./Code.gs) の内容を貼り付けて保存（💾）します。

## 2. 管理者パスワードを登録する

1. スプレッドシートのタブに戻り、ページを再読み込みします。
2. メニューに「工事費ツール」が表示されるので、「工事費ツール」→「管理者パスワードを設定」を選びます。
   - 初回は Google の承認画面が出ます。「続行」→ 自分のアカウントを選択 →「詳細」→「（安全ではないページ）に移動」→「許可」の順に進めてください（自分で作ったスクリプトのため問題ありません）。
3. 工事費判定ツールの管理者ページと**同じパスワード**を入力して OK を押します。

パスワードはスプレッドシート上には表示されず、照合用のハッシュ値だけがスクリプトのプロパティに保存されます。

## 3. ウェブアプリとしてデプロイする

1. Apps Script の画面右上「デプロイ」→「新しいデプロイ」を押します。
2. 「種類の選択」の歯車 →「ウェブアプリ」を選びます。
3. 次のように設定して「デプロイ」を押します。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 表示された「ウェブアプリの URL」（`https://script.google.com/macros/s/…/exec`）をコピーします。

## 4. 工事費判定ツールに URL を設定する

- **全端末に反映する場合**：URL をツール本体の `SHEET_API_URL` に組み込みます（現在のツールには組み込み済みです。デプロイをやり直してURLが変わった場合のみ再設定が必要です）。
- **すぐに試す場合**：ツールの「⚙ 管理者」→ 管理者ページ下部の「スプレッドシート連携」に URL を貼り付けて「接続」を押します（その端末のブラウザだけに設定されます）。

接続したあと、スプレッドシートが空の場合は管理者ページで「保存」を押すと、現在の工事費がスプレッドシートに登録されます。

## 使い方・注意事項

- 管理者ページで「保存」すると、スプレッドシートの「工事費単価」「機器」「追加工事項目」シートが更新され、「更新履歴」シートに記録が残ります。
- 他の端末には、ツールを開き直した時点で反映されます。
- スプレッドシートの金額を直接書き換えても反映されます。**「キー」「ID」列は変更しないでください。**
- スプレッドシートに接続できない場合は、前回取得した金額で表示し、画面上部に警告を出します。
- パスワードを10回続けて間違えると、10分間保存できなくなります。
- `Code.gs` を修正した場合は「デプロイ」→「デプロイを管理」→ 鉛筆アイコン →「バージョン：新バージョン」→「デプロイ」で更新してください（URL は変わりません）。
